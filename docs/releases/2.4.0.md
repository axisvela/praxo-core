# PRAXO-CORE 2.4.0

**Released:** 2026-10-24

PRAXO-CORE 2.4.0 is an adoption-surface refresh. It changes no exported
`pkg/...` declarations and does not claim production or external validation.

## Highlights

- **Streaming quickstart.** `examples/quickstart` prints text deltas through
  `agent.Options.OnDelta`, keeps lifecycle events on stderr, and has a
  deterministic SSE regression test.
- **MCP resources and prompts example.** `examples/ecosystem/mcp` is a separate
  module that lists and reads resources and prompts from an in-memory MCP
  server. It keeps the MCP SDK out of the core module.
- **Memory recall benchmark.** `BenchmarkAgentMemoryRecall` measures agent-loop
  recall against a deterministic 20-record store.
- **Release documentation.** Optional modules are documented as independent
  `adapters/<name>/vX.Y.Z` tags.
- **CI coverage.** The new MCP example is checked in the examples and
  cross-platform module-security jobs.

## Upgrade

```bash
go get github.com/axisvela/praxo-core/v2@v2.4.0
```

No source migration is required from 2.3.6. `api/2.4.0.txt` is identical to
`api/2.3.6.txt`. Optional adapter versions are unchanged.

Use Go 1.26.10, the tested toolchain.

## Validation

- Full local tests, vet, and build pass.
- The quickstart SSE test and MCP example test pass.
- Benchmark scenarios, including memory recall, run with `-benchtime=10x`.
- `mkdocs build --strict` passes.
- These checks do not establish live-provider, deployed, external adoption, or
  independent security validation.

## Scope

- This release is an adoption-surface refresh, not the 2.4.0 external-evidence
  milestone originally sketched in the roadmap. The remaining evidence items
  move to 2.5.0.
- #3 (OpenTelemetry option in the reference app) and the independent validation,
  external adoption, and containment-review items remain open.

## Release Tag

No signing key was configured for this release environment. The tag is
annotated rather than cryptographically signed; checksums and an SBOM are
published by the release workflow.
