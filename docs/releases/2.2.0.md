# PRAXO-CORE 2.2.0

**Released:** 2026-10-23

PRAXO-CORE 2.2.0 is an ecosystem-depth additive release. The exported `pkg/...`
API is unchanged from 2.1.0.

## Highlights

- **Protocol adapters:** MCP resources/prompts, OpenTelemetry, Harmovela HTTP
  events, and A2A server execution.
- **Model adapters:** native Anthropic Messages and Gemini generateContent
  adapters with tool/function calls and SSE streaming.
- **Multi-agent:** optional supervisor/sequential delegation plus a runnable
  subagent example and boundary guidance.
- **Examples:** process/WASM plugins, checkpoint/resume, sandbox/policy, and
  multi-agent delegation.
- **Fixes:** MCP input schemas are preserved for model-facing tools; OTel
  excludes event data by default.

## Upgrade

```bash
go get github.com/axisvela/praxo-core/v2@v2.2.0
```

No source changes are required for consumers of 2.1.0. `api/2.2.0.txt` is
identical to `api/2.1.0.txt`.

## Optional Modules

Optional adapters are versioned independently:

- `adapters/mcp/v0.2.0`
- `adapters/otel/v0.2.0`
- `adapters/anthropic/v0.1.0`
- `adapters/gemini/v0.1.0`
- `adapters/harmovela/v0.1.0`
- `adapters/a2a/v0.1.0`
- `adapters/multiagent/v0.1.0`

## Validation

- API diff from 2.1.0: no changes
- Published-module consumer check: core and all optional modules compile and run
  without local replacements
- CI: test, vet, build, race, fuzz, staticcheck, govulncheck, benchmarks
- Docs site built with `mkdocs build --strict`

## Limits

- Adapter integration tests are deterministic protocol tests; they do not prove
  live-service or production validation.
- Multi-agent support is subagent delegation and an optional supervisor module,
  not a built-in graph runtime. Durable graph execution belongs to RHEOVELA.
- A2A currently validates the executor protocol mapping, not full JSON-RPC/gRPC
  interoperability with an external A2A peer.
