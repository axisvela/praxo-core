# PRAXO-CORE 2.1.0

**Released:** 2026-10-22

PRAXO-CORE 2.1.0 is an adoption-focused additive release. The `pkg/...` API is
unchanged from 2.0.0.

## Highlights

- **OpenAI-compatible adapter.** `adapters/openaicompat` supports tool calls,
  tool choice, usage accounting, and SSE streaming.
- **MCP tool gateway.** `adapters/mcp` maps MCP tools to `tool.Gateway` and is
  published as a separate module.
- **Runnable examples.** Quickstart, reference workspace agent, ecosystem
  adapter skeletons, and real NOETIVELA/Mnemovela/GNOSIVELA SDK recipes.
- **Docs and recipes.** Bilingual docs site, adoption guide, integration
  recipes, benchmarks, and deeper AxisVela comparison.
- **Community.** Contributing guide, code of conduct, issue/PR templates, and
  GitHub Discussions.

## Upgrade

```bash
go get github.com/axisvela/praxo-core/v2@v2.1.0
```

No source changes are required for consumers of 2.0.0. The exported `pkg/...`
API and `api/2.1.0.txt` are identical to `2.0.0`.

## New Modules and Packages

| Package | Module | Purpose |
| --- | --- | --- |
| `adapters/openaicompat` | `github.com/axisvela/praxo-core/v2` | OpenAI-compatible model adapter with streaming |
| `adapters/mcp` | `github.com/axisvela/praxo-core/adapters/mcp` | MCP tools through `tool.Gateway` |

The MCP module is tagged `adapters/mcp/v0.1.0`.

## Validation

- Linux CI: test, vet, build, race, fuzz, staticcheck, govulncheck, benchmarks
- API diff from 2.0.0: no changes
- SBOM and checksums attached to the GitHub release
- Docs site deployed with `mkdocs build --strict`

## Notes

- The NOETIVELA SDK exposes text content, not tool calls. Use a custom HTTP
  adapter for tool calling.
- GNOSIVELA has no `v3` semver tag yet; the SDK recipe pins a pseudo-version.
- MCP authentication belongs to the client session; the gateway token argument
  is ignored.
