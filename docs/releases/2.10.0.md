# PRAXO-CORE 2.10.0

**Released:** 2026-11-20

PRAXO-CORE 2.10.0 is the framework release that records provider streaming and
process plugin host support across the declared language cores. Language SDKs
are versioned independently; their source tags are listed in the language
matrix and release index.

## Highlights

- OpenAI-compatible, Anthropic, and Gemini SSE streaming adapters with content,
  tool-call, usage, and finish-reason reassembly.
- JSON-Lines process plugin hosts with token authentication, health handshake,
  invocation timeout, cancellation, and typed call errors.
- Go, Python, TypeScript, Java, Rust, C#, Dart, Ruby, Elixir, Erlang, Haskell,
  V, OCaml, Fortran, C, Zig, Julia, D, Delphi, PHP, Objective-C, Nim, and C++
  process-host integrations.
- COBOL integration through the C `*_simple` ABI and a Java-backed
  MATLAB/Octave text-payload host.
- Go reference WASM host (`pkg/plugin/host/wasm`) with a bounded guest ABI,
  hermetic modules, timeout/cancellation, memory limits, and evidence hooks.
- Minor source releases for every declared language SDK.

## Upgrade

```bash
go get github.com/axisvela/praxo-core/v2@v2.10.0
```

Language consumers should adopt the corresponding language tag instead of the
Go module tag. Published package versions remain independent and may lag their
source tags.

## Verification

- Go tests, vet, and API snapshot pass.
- Language conformance and API snapshot checks run in the release CI.
- `scripts/check_language_releases.py` validates manifests, tags, release notes,
  matrix rows, and support-page versions.

Process host conformance does not imply WASM or container isolation. COBOL does
not expose a native supervision API, and the MATLAB/Octave adapter remains a
partial text-payload host without binary payloads, concurrent calls, or
cancel-before-kill.
