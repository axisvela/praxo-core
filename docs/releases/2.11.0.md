# PRAXO-CORE 2.11.0

**Released:** 2026-11-26

PRAXO-CORE 2.11.0 is a documentation and packaging release for the Go reference
Core. It moves the runnable example tree under `language/go/examples`, links
scenario tutorials and reference applications from the language registries, and
refreshes release metadata for the independent language source tags. It does not
change the exported `pkg/...` API or the shared wire contract.

## Highlights

- Runnable Go examples now live under `language/go/examples`, keeping the
  repository root focused on the framework and shared specification.
- Language registry pages link their scenario tutorials and AI-native reference
  applications alongside the existing source and package metadata.
- Community discovery links are available from the README, registry entry, and
  documentation site.
- Minor source releases for each declared language SDK; package registries remain
  independently versioned.

## Upgrade

No Go code changes are required. Update example paths that referenced the old
root `examples/` directory to `language/go/examples/`.
