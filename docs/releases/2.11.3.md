# PRAXO-CORE 2.11.3

**Released:** 2026-11-27

PRAXO-CORE 2.11.3 is a documentation release for the Go reference Core. It adds
scenario-tutorial and reference-application lists to the root README and brings
the public registry, support, and evidence pages in line with the current
published versions, including Java 0.12.2. It does not change the exported
`pkg/...` API or the shared wire contract.

## Highlights

- The root README lists representative scenario tutorials and the
  reference-application portfolio, with links to source and acceptance limits.
- Registry and support pages identify Go `v2.11.3` and Java `0.12.2`.
- The release contains no Go source or wire-contract changes.

## Upgrade

Run `go get github.com/axisvela/praxo-core/v2@v2.11.3`. No code changes are
required.
