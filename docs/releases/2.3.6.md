# PRAXO-CORE 2.3.6

**Released:** 2026-10-24

This patch fixes `pkg/formatter` runtime and mutation behavior. It changes no
exported `pkg/...` declarations.

## Formatter

- `Formatter.Run` returns an error for an empty command instead of panicking.
- `List`, `AllAvailable`, and `Detect` no longer expose the registry's extension
  slice to callers.
- `WatchFormat.FormatAll` returns filesystem walk errors instead of always
  returning a nil error.
- Tests cover unknown extensions, case-insensitive detection, caller mutation
  isolation, empty and failed commands, missing directories, and real `gofmt`
  formatting.

Formatter detection still picks the first available registry entry. Commands are
split on whitespace and do not support quoted arguments, and formatting is not a
sandbox.

## Verification

- Full local tests, vet, and build pass.
- `pkg/formatter` statement coverage increased from 4.7% to 83.3%.
- Exported API is unchanged from 2.3.5.
- These checks do not establish production or external validation.

## Upgrade

```bash
go get github.com/axisvela/praxo-core/v2@v2.3.6
```

Use Go 1.26.10, the tested toolchain. No source migration is required from
2.3.5. Optional adapter versions are unchanged.

## Release Tag

No signing key was configured for this release environment. The tag is
annotated rather than cryptographically signed; checksums and an SBOM are
