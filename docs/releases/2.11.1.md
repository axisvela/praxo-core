# PRAXO-CORE 2.11.1

**Released:** 2026-11-27

PRAXO-CORE 2.11.1 is a documentation correction release for the Go reference
Core. It makes the root README lead with the Go reference module and corrects
its install command to `v2.11.1`. It also reconciles the public release and
registry documentation with the current version. It does not change the
exported `pkg/...` API or the shared wire contract.

## Highlights

- The root README presents `github.com/axisvela/praxo-core/v2` as the Go
  reference module, with the current `go get` command.
- Release and registry documentation identify `v2.11.1` as the current Go
  release.
- The release contains no Go source or wire-contract changes.

## Upgrade

Run `go get github.com/axisvela/praxo-core/v2@v2.11.1`. No code changes are
required.
