# PRAXO-CORE 2.3.1

**Released:** 2026-10-23
**Tag:** annotated `v2.3.1` (no signing key configured)

PRAXO-CORE 2.3.1 is a patch release that hardens the 2.3.0 lifecycle and
documentation surface. It adds no exported `pkg/...` declarations.

## Highlights

- **A2A gRPC coverage:** the adapter now has an in-process gRPC client/server
  round-trip test alongside the JSON-RPC test.
- **Wait/prune correctness:** `SubagentManager.Wait` returns the terminal
  snapshot to every concurrent waiter, including when the task is pruned while
  they wait.
- **Event-driven examples:** `examples/multiagent` and the multi-agent docs use
  `SubagentManager.Wait` instead of polling.
- **Safer recipe:** the sandbox policy recipe accepts both `[]string` and
  `[]any` command arguments, fails closed, and no longer references an
  out-of-scope variable.
- **Streamed usage docs:** the OpenAI-compatible recipe documents
  `IncludeUsage`.
- **Published consumer lifecycle:** `tests/consumer` runs the published
  `Wait`/`Prune` lifecycle.
- **Docs gate:** the docs workflow builds pull requests with
  `mkdocs build --strict`.

## Upgrade

```bash
go get github.com/axisvela/praxo-core/v2@v2.3.1
```

No source changes are required for consumers of 2.3.0. `api/2.3.1.txt` is
identical to `api/2.3.0.txt`.

## Optional Modules

Unchanged: `adapters/multiagent/v0.2.0`, `adapters/mcp/v0.3.0`,
`adapters/otel/v0.2.0`, `adapters/anthropic/v0.1.0`,
`adapters/gemini/v0.1.0`, `adapters/harmovela/v0.1.0`, and
`adapters/a2a/v0.1.0`.

## Validation

- Core, adapter, example, and published-consumer test/vet/build suites pass.
- Docs build with `mkdocs build --strict`.
- Staticcheck and govulncheck pass.
- Linux CI remains the race-detector gate.

## Limits

- Adapter tests are deterministic protocol tests; they do not prove live
  service or production validation.
- A2A covers in-process JSON-RPC and gRPC round trips, not an external peer.
- Multi-agent support remains subagent delegation plus an optional supervisor
  module, not a durable graph runtime.
