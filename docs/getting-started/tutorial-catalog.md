## Counting Rules

There are **681 indexed entries**, not that many distinct industry scenarios or verified applications.
Language variants, overlapping themes, mechanism cells and tutorial slices are not additive unique scenarios.

| 类型 / Type | 数量 / Count |
| --- | ---: |
| New candidate goals (not implementations) | 100 |
| Earlier broad scenario themes (overlap the new goals) | 22 |
| Application tutorial language paths | 79 |
| Cross-cutting tutorial guides (overlap source paths) | 6 |
| Language/theme mechanism source entries | 403 |
| Advanced language/theme source entries | 29 |
| Other source examples and recipes | 42 |

Full scenario goals: **100**; **76** have related partial slices; full implementations: **0**. Related goals remain candidates; slice relations do not add indexed entries.

The MATLAB/Octave paths share an implementation, not two unique scenarios; native MATLAB is unverified.
README and source existence is not runtime or CI verification. See [Tutorial status](tutorial-plan.md#current-status) and [verification evidence](../project/verification-evidence.md).
