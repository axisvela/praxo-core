# 发布要求

核心、语言 SDK、可选适配器和共享规范独立版本化。每次发布必须说明范围与兼容影响。

## 验证要求

- 更新对应版本文件、变更日志和用户可见的发布说明。
- 通过受影响工件的构建、测试、API 和安全检查。
- SDK 通过声明范围的一致性向量与 parity 检查。
- 检查依赖许可，生成适用的 SBOM 和校验和。
- 验证版本标签，优先使用签名标签，例外需要记录。
- 验证用户实际使用的分发工件可以安装。

| 工件 | 标签 |
| --- | --- |
| Go 核心 | `vX.Y.Z` |
| 共享规范 | `spec/vX.Y.Z` |
| 语言 SDK | `<language>/vX.Y.Z` |
| 可选 Go 适配器 | `adapters/<name>/vX.Y.Z` |

既有标签不可移动。SDK 必须声明支持的契约版本。根发布工作流只处理 `v*` 核心标签，
SDK 或适配器的源码标签不会自动完成包管理器发布。

升级前查看[版本总览](../releases/index.md)、[兼容性](compatibility.md)和
[SDK 支持政策](../sdks/support.md)。产品版本与框架版本独立。
