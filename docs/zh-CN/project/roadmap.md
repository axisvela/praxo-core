# 公开路线图

当前核心版本为 `2.5.2`。本文说明技术方向，不承诺交付排期，也不表示所有 Core
都具有每一项功能。

## 当前方向

优先证明行为，而不是增加语言、提供商或工具数量。以下是验收目标，不表示工作已经完成。

| 方向 | 验收目标 |
| --- | --- |
| 发布与验证完整性 | 文档和发布门禁与规范版本元数据一致；跳过项和旧报告不能被记为本次通过 |
| 受治理集成 | 缺少必要控制、授权拒绝或安全依赖故障时阻止执行；最终工具参数仍受授权约束 |
| 上下文信任 | Memory、Skill、工具结果和压缩摘要保留来源与信任差异，不隐式提升为受信任指令 |
| 业务效果恢复 | 固定版本的集成测试区分执行意图、业务提交、证据持久化和结果不确定；重试不盲目重复效果 |
| 隔离能力 | 文件系统竞态、进程树逃逸和 WASM 资源耗尽测试明确平台限制与剩余风险 |
| 提供商与可观察性证据 | 可运行的事件/OpenTelemetry 示例和真实工作区提供商验证仅支撑实测范围；工作区契约晋级需要两提供商复核 |
| 语言支持 | 分别报告契约一致性、功能覆盖和运行验证；agent-capable 实现以十九个行为场景为目标，extended 实现在有明确消费者和维护者时选择性推进；未覆盖单元格保持显式 |

## 行为能力层级

行为覆盖与契约层级分开跟踪：

| 层级 | 语言 | 当前目标 |
| --- | --- | --- |
| Agent-capable | Go、Python、TypeScript、Java、Rust、R、C# | 全部十九个行为实验场景；缺口保持显式 |
| Extended | C、PHP、Fortran、COBOL、Ruby、Elixir、Erlang、C++、Lua | 仅在有明确消费者和维护者时逐场景推进 |
| Optional | 其他已声明实现 | 不在行为计划内；契约一致性不变 |

clean 十六语言报告为 152 passed、152 个显式 unsupported、无失败。R 和 C 已接入；C# 与 PHP 包含三个生命周期场景。不要把 unsupported 当作失败或通过，也不要仅为提高数量而增加语言或场景。

边界设计见[受治理执行设计](../reference/governed-execution.md)。环境、配置、过程、数据、
结果和发现的记录要求见[测试证据规范](../contributing/test-evidence.md)。

## 验证边界

Core 测试验证框架行为；跨仓库测试仅验证实际执行的集成与版本。历史本地服务运行是有价值的
证据，但不证明当前发布版本、独立复现或生产就绪。

行为实验与兼容性报告会注明被测 revision。后续仅文档提交不会扩展该证据；为新 revision 引用报告前必须重跑或重新绑定。

新增共享安全或效果契约必须先有明确消费者和负向测试，再考虑公开 API。
身份签发、策略决策服务、效果账本和持久化工作流仍由集成层负责。
本设计本身不改变默认行为或公开 API。

## 兼容承诺

保持 Go 公开 API 精简、MIT 边界完整，新契约需要消费者和测试。不能仅为移植 Core
扩大 Go API。参见[兼容政策](compatibility-policy.md)、[Core 支持](../languages/support.md)
与[语言规范](../contributing/language-policy.md)。
