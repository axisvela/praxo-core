# PRAXO-CORE 集成

## 与 PRAXOVELA

PRAXOVELA 是第一个基于 PRAXO-CORE 构建的产品。产品提供：

- 提供商/模型路由
- 工具注册表与沙箱组装
- 会话/运行持久化与检查点存储
- HTTP/SSE API
- 持久化调度器
- 桌面外壳
- 策略与审批执行
- 插件物化、签名信任、SBOM/证据与滚动更新

框架提供插件契约层、进程/WASM 宿主、通用宿主桥接和一致性测试套件。
PRAXOVELA 通过轻量别名导入这些宿主，以保持产品行为不变。

`pkg/httpclient` 可被产品适配器复用；供应商特定认证、租户策略、授权/纪元
语义和信任存储仍归产品所有。

## 与外部集成方

外部集成方可以直接实现框架接口：

- 针对其提供商的模型适配器
- 针对其能力的工具适配器
- 针对其存储的记忆适配器
- 针对其总线的事件适配器
- 针对其授权系统的策略适配器
- 针对其执行环境的沙箱适配器
- 用于持久化恢复的检查点存储
- 针对其运行时的插件宿主/桥接接线

## 检查点与恢复

`pkg/checkpoint` 定义持久化快照和存储契约。框架不内置存储；持久化和恢复策略
由产品负责。

会话恢复通过加载最新检查点并预先填充 `agent.Session.Messages` 实现。
[checkpoint 示例](https://github.com/axisvela/praxo-core/tree/main/examples/checkpoint)
展示了一个小型内存存储和恢复流程。

生产存储应增加持久化、租户隔离、加密、保留策略和恢复测试。

## 非目标

- 不要导入 PRAXOVELA 内部包。
- 不要复制 PRAXOVELA 的产品组装。
- 不要让框架负责持久化调度触发。
- 不要自我认证验证。
- 不要把提供商凭据、租户策略或信任存储放入框架。
