# PRAXO-CORE 2.2.0

**发布日期：** 2026-10-23

PRAXO-CORE 2.2.0 是聚焦生态深度的增量版本。导出的 `pkg/...` API 与 2.1.0
保持一致。

## 重点

- **协议适配器：** MCP resources/prompts、OpenTelemetry、Harmovela HTTP 事件、
  A2A 服务端执行。
- **模型适配器：** 原生 Anthropic Messages 与 Gemini generateContent 适配器，
  支持工具/function call 和 SSE 流式输出。
- **多 Agent：** 可选的 supervisor/顺序委派模块、可运行子 Agent 示例和边界指南。
- **示例：** process/WASM 插件、checkpoint/resume、sandbox/policy、多 Agent 委派。
- **修复：** MCP 面向模型的工具保留输入 schema；OTel 默认不导出事件数据。

## 升级

```bash
go get github.com/axisvela/praxo-core/v2@v2.2.0
```

2.1.0 的使用方无需修改源码。`api/2.2.0.txt` 与 `api/2.1.0.txt` 相同。

## 可选模块

可选适配器独立版本化：

- `adapters/mcp/v0.2.0`
- `adapters/otel/v0.2.0`
- `adapters/anthropic/v0.1.0`
- `adapters/gemini/v0.1.0`
- `adapters/harmovela/v0.1.0`
- `adapters/a2a/v0.1.0`
- `adapters/multiagent/v0.1.0`

## 验证

- 与 2.1.0 的 API 差异：无变化
- 已发布模块消费测试：核心和所有可选模块可在无本地 replace 的情况下编译和运行
- CI：test、vet、build、race、fuzz、staticcheck、govulncheck、benchmarks
- 文档站通过 `mkdocs build --strict`

## 限制

- 适配器集成测试是确定性协议测试，不代表实网服务或生产验证。
- 多 Agent 支持是子 Agent 委派和可选 supervisor 模块，不是内置图运行时。
  持久化图执行属于 RHEOVELA。
- A2A 当前验证 Executor 协议映射，尚未完成与外部 A2A peer 的完整
  JSON-RPC/gRPC 互操作测试。
