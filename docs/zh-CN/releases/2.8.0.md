# PRAXO-CORE 2.8.0

**发布日期：** 2026-11-14

PRAXO-CORE 2.8.0 是次版本发布。它为 Go 参考实现增加显式的安全默认值选项，并扩充可运行的治理示例。导出的 `pkg/...` API 新增两个 `agent.Options` 字段；现有调用方无需修改源码。

## 重点

- **安全默认值。** `agent.Options.RequirePolicy` 在未配置 `Policy` 时拒绝构造；`RequireToolScope` 在 `AllowedTools` 为空时拒绝构造。两者均为 opt-in，默认 `false`。
- **HITL 示例。** `examples/hitl` 先批准一次写操作，再编辑参数并验证最终参数重新授权会阻止副作用。
- **多轮 checkpoint 示例。** `examples/session-checkpoint` 在两次 agent 运行之间保存、恢复并继续会话。
- **带参数 live 工具。** live-model 示例使用 `get_time(zone)`，通过小型 JSON Schema 向真实模型暴露工具参数契约。
- **Go mirror。** mirror 同步现在支持 `axisvela/praxo-core-go`，包含根 Go module、示例、API snapshot 和 `spec/`。

## 升级

```bash
go get github.com/axisvela/praxo-core/v2@v2.8.0
```

现有调用方无需修改源码。新字段为 opt-in；未设置时保持原有行为。

## 验证

- 发布提交要求根模块 test、vet、build、race、API snapshot 和 fuzz 检查通过。
- `api/2.8.0.txt` 记录新增的 `RequirePolicy` 和 `RequireToolScope` 字段。
- HITL 与 session-checkpoint 示例有对应测试。
- mirror 同步与严格文档构建通过。

## 限制

- 安全默认值只是构造期守卫，不认证身份、不验证 provider 行为，也不在应用效果边界强制授权。
- checkpoint 是恢复提示，不是事务，也不是 exactly-once 保证。
- Go 工具调用已接受 `context.Context`；非 Go 的取消 API 仍待后续版本。
