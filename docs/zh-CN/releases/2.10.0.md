# PRAXO-CORE 2.10.0

**发布日期：** 2026-11-20

PRAXO-CORE 2.10.0 记录各已声明语言 Core 的 Provider 流式适配与进程插件宿主支持。
各语言 SDK 独立版本化，源码标签见语言矩阵和发布索引。

## 重点

- OpenAI-compatible、Anthropic 和 Gemini SSE 流式适配，重组内容、工具调用、
  usage 和结束原因。
- JSON-Lines 进程插件宿主，支持 token 认证、健康握手、调用超时、取消和类型化
  调用错误。
- Go、Python、TypeScript、Java、Rust、C#、Dart、Ruby、Elixir、Erlang、Haskell、
  V、OCaml、Fortran、C、Zig、Julia、D、Delphi、PHP、Objective-C、Nim 和 C++
  的进程宿主集成。
- COBOL 通过 C `*_simple` ABI 集成；MATLAB/Octave 提供 Java 支撑的文本 payload
  宿主。
- 所有已声明语言 SDK 发布 minor 源码版本。

## 升级

```bash
go get github.com/axisvela/praxo-core/v2@v2.10.0
```

语言消费者应使用对应的语言标签，而不是 Go 模块标签。包管理器中的已发布版本
独立维护，可能滞后于源码标签。

## 验证

- Go tests、vet 和 API 快照通过。
- 发布 CI 运行各语言 conformance 与 API 快照检查。
- `scripts/check_language_releases.py` 校验清单、标签、发布说明、矩阵和
  支持页版本。

进程宿主一致性不代表 WASM 或容器隔离。COBOL 不提供原生托管 API；
MATLAB/Octave 适配器仍是部分文本 payload 宿主，不支持二进制 payload、
并发调用或 cancel-before-kill。
