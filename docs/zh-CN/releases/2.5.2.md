# PRAXO-CORE 2.5.2

**发布：** 2026-10-30

PRAXO-CORE 2.5.2 是安全与行为修正补丁。导出 `pkg/...` 声明与 `2.5.1` 相同；
`api/2.5.2.txt` 是有意保持不变的声明基线。本地 VFS 在路径授权后通过 rooted handle 执行
实际文件操作，并拒绝绝对 symlink。

## 重点

- **Rooted 本地 VFS。** `pkg/vfs/localfs` 在 `policy.PathChecker` 授权后，使用 `os.Root`
  执行读、写、stat、列表、删除、glob 和 Grep 文件访问。检查后发生的 symlink swap 不能再把
  实际操作重定向到 workspace root 之外。
- **Symlink 行为变化。** 本地 VFS 现在拒绝绝对 symlink；workspace symlink 必须使用相对
  target。这是明确记录在“限制”章节中的安全例外。
- **受治理工作区参考。** 必需控制、最终参数授权、单次审批、审批后修改拒绝、排队撤销和
  masked tool error 均有确定性 fixture。
- **上下文信任参考。** 显式示例分离部署指令、摘要绑定的批准 Skill、不可信 memory/tool/
  summary 数据和文本恢复，不改变普通 Agent 默认行为。
- **OpenTelemetry 示例。** 可运行内存 exporter 展示事件 span 和排除工具参数/结果的
  allowlist。
- **验证证据索引。** 公开证据记录 Core、containment、adapters、A2A/IAM 契约、集成恢复和
  产品 effect ledger 的证据级别与限制。
- **CI 与契约治理。** 新增 verbose Linux containment job；语言 parity 文档区分契约一致性、
  功能覆盖和运行证据。

## 升级

```bash
go get github.com/axisvela/praxo-core/v2@v2.5.2
```

导出 `pkg/...` API 不需要源码迁移。如果 workspace 中存在绝对 symlink，请先改为相对 target
再升级，或继续使用 `2.5.1` 直到完成迁移。

## 验证

- 发布提交要求根 Go tests、vet、build、API snapshot、race、fuzz 和 module-security 检查。
- `api/2.5.2.txt` 与 `api/2.5.1.txt` 相同。
- Linux containment CI 以 verbose 输出运行 symlink 用例；没有 symlink 权限的 Windows 主机
  会报告 SKIP。
- 公开验证证据索引记录本地集成恢复结果及其限制。

## 限制

- `localfs` 之外的 `policy.PathChecker` 决策仍是 check-then-use；高风险管理调用方仍需
  OS-level confinement。
- 无法创建 symlink 的 Windows 主机未验证 Windows symlink 行为。
- Linux cgroup v2 containment、确定性 WASM fuel、live workspace provider、独立安全评审和
  生产就绪仍开放。
- 本地集成恢复是 loopback/本地 PostgreSQL 证据，不是部署、网络分区、并发负载或生产测试。
- 拒绝绝对 symlink 是补丁兼容规则的明确安全例外；发布评审必须保留此说明和受影响行为。
