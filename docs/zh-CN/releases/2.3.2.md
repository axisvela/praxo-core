# PRAXO-CORE 2.3.2

**发布日期：** 2026-10-23

PRAXO-CORE 2.3.2 是修复 Gemini 流式候选选择并加固 provider 与安全 recipe 的
补丁版本。它不新增导出 `pkg/...` 声明。

## 重点

- **Gemini 流式：** 适配器现在只消费每个流式响应中的首个候选，与非流式行为一致，
  避免将其他候选的文本或工具调用混入结果。
- **Provider recipe：** MCP 注册改用 `NewTools` 以保留输入 schema；策略与出站
  recipe 说明静态路由和凭据处理；事件 recipe 说明数据卫生边界。
- **安全示例：** sandbox recipe 对将要执行的同一条命令授权，并明确策略门控的宿主
  执行不是 OS 级隔离。reference workspace 策略只允许 `model.generate` 和 `fs.*`
  调用。

## 升级

```bash
go get github.com/axisvela/praxo-core/v2@v2.3.2
```

2.3.1 的消费者无需修改源码。`api/2.3.2.txt` 与 `api/2.3.1.txt` 相同。

## 可选模块

`adapters/gemini/v0.1.1` 包含 Gemini 流式修复。其他已发布的可选模块 tag 不变。

## 验证

- 核心、adapter、ecosystem SDK 与示例的 test/vet/build 通过。
- 文档通过 `mkdocs build --strict`。
- staticcheck 与 govulncheck 通过。
- Linux CI 仍是 race detector 门禁。

## 限制

- Adapter 测试是确定性协议测试，不代表实网服务或生产验证。
- 真实 provider 验证需要按需提供凭据，并独立处理计费、限流和密钥控制。
- A2A 覆盖进程内 JSON-RPC 与 gRPC 往返，不代表外部 peer。
