# PRAXO-CORE 2.7.0

**发布日期：** 2026-11-09

PRAXO-CORE 2.7.0 是次版本发布。导出的 `pkg/...` 声明与 `2.6.0` 相同；
`api/2.7.0.txt` 记录同一声明基线。本次发布集中于可运行的长运行操作与集成配方、
已发布包升级检查，以及采用与具身证据更新，不新增 `pkg/...` API。

## 重点

- **长运行操作。** Go 长运行配方现在在 rename 边界前后注入确定性故障，拒绝合法但
  未提交的临时状态，并对损坏的已提交状态 fail closed。其 fencing fixture 建模租约
  过期、续约和撤销，并支持重启后持久化；边界测试记录并发写入导致的丢失更新。
- **独立服务与验证器。** 配方构建独立服务，提供健康/就绪端点、bearer 认证、可选
  TLS、优雅关闭、基础请求/错误/操作指标、基于环境变量的配置，以及无需重启的
  文件型 token/secret 轮换。独立验证器二进制使用自己的 token 与签名密钥。
- **租约后端与恢复。** 变更可使用文件、SQLite 或 Postgres 租约，并在租约下执行
  reload-modify-save。进程级崩溃测试覆盖提交边界；受门禁控制的 100 次提交负载/
  故障测试和全新检出复现脚本验证已确认操作的恢复。
- **集成配方。** 适配器一致性、重试安全、事件 sink、上下文预算、检查点存储、
  结构化输出、VFS 隔离、provider 回退、插件生命周期、多 Agent 委派、流式以及
  workspace session 契约均提供离线可运行配方。
- **已发布包升级。** Python `0.2.4` -> `0.3.0`、TypeScript `0.1.5` -> `0.2.0`、
  Java `0.3.0` -> `0.4.0` fixture 安装历史包、升级源码不变的消费者，并重跑
  starter/治理套件。
- **采用与具身证据。** 文档记录一次有界的 opencode 采用试点、Claude Code 结构性
  发现，以及 AKROVELA 的产品侧适配器与确定性 P1 切片；完整基线与 E1-E8 试点仍明确
  未完成。

## 升级

```bash
go get github.com/axisvela/praxo-core/v2@v2.7.0
```

导出的 `pkg/...` API 无需源码迁移。`api/2.7.0.txt` 与 `api/2.6.0.txt` 相同。

## 验证

- 发布提交需要通过根 Go 测试、vet、build、静态分析、漏洞扫描、API snapshot 与
  fuzz 检查。
- `scripts/check_release_metadata.py` 校验 `VERSION`、API snapshot、两份发布说明、
  变更日志、两个版本索引、Go 模块主版本与编程 Agent 包映射。
- 消费者与配方检查安装已发布包，并运行确定性 allow/deny、治理与长运行测试。
  Postgres 租约测试由 `PRAXO_POSTGRES_DSN` 门禁控制。

## 限制

- 长运行工作是 L4 应用配方证据，不是生产部署、Core 能力声明或 exactly-once 保证。
- live Postgres 验证仍未完成：2026-11-09 在 Windows 上使用 PostgreSQL 18.1 的本地
  尝试未完成（服务器以 `0xC0000142` 退出）。
- OS 级掉电证明、生产租约协调、可信时钟与 live collector/告警仍未验证。
- 采用基线不完整，后续变更后的留存未观察，Codex/Copilot 仍未验证。
- 具身仿真、独立观测/验证器、ROS 2 执行、硬件效果与 E1-E8 试点证据仍未完成。
- 源码 tag 不会把本地证据转为生产验收。
