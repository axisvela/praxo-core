# PRAXO-CORE 2.3.0

**发布：** 2026-10-23

PRAXO-CORE 2.3.0 聚焦执行正确性、生命周期控制与有界并发。它在已冻结的
`pkg/...` 表面上新增两个导出方法，其余接口不变。

## 重点

- **子 Agent 生命周期：** `SubagentManager.Wait` 通过完成事件阻塞等待，
  `SubagentManager.Prune` 清理过期终态任务。`Cancel` 不再覆盖终态，`Update`
  只接受运行中的任务。
- **真正的并行组合：** `flow.Parallel` 并发执行 Runnable，保持输出顺序，并在
  全部结束后按索引返回第一个错误。
- **有界多 Agent 监督：** `adapters/multiagent` 改为事件驱动等待，不再轮询；
  `MaxConcurrency` 限制并行 worker 数量。
- **流式用量：** `adapters/openaicompat` 可请求
  `stream_options.include_usage`，并将流式 token 用量映射到 `model.Usage`。
- **记忆存储：** 生成的 ID 避免碰撞，`Put` 时预计算搜索文本，零值可用。
- **MCP 分页：** resources 与 prompts 列表拒绝重复 cursor；多页列表已有测试。

## 升级

```bash
go get github.com/axisvela/praxo-core/v2@v2.3.0
```

2.2.0 的消费者无需修改源码。`api/2.3.0.txt` 与 `api/2.2.0.txt` 的差异仅为
`SubagentManager.Wait` 和 `SubagentManager.Prune`。

- 新增：`adapters/multiagent/v0.2.0`
- 新增：`adapters/mcp/v0.3.0`

## 验证

- 与 2.2.0 的 API 差异：两个新增方法，无删除或签名变更
- CI：test、vet、build、race、fuzz、staticcheck、govulncheck、benchmarks
- 文档站通过 `mkdocs build --strict`
- 已发布模块消费测试更新到 2.3.0 tag

## 限制

- 适配器集成测试是确定性协议测试，不代表实网服务或生产验证。
- A2A 覆盖进程内 HTTP JSON-RPC 往返，不代表外部 peer 或 gRPC 互操作。
- 多 Agent 仍是子 Agent 委派加可选 supervisor 模块，不是持久化图运行时。
  持久化图执行属于 RHEOVELA。
