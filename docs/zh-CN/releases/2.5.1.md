# PRAXO-CORE 2.5.1

**发布日期：** 2026-10-28

PRAXO-CORE 2.5.1 是 2.5.0 之后的安全与行为修正补丁版本。导出的 `pkg/...`
声明未变化；API 快照差异仅为包注释文字。

## 重点

- **PII 历史参数脱敏。** PII Middleware 现在会脱敏重新进入模型历史中的工具调用
  参数，包括嵌套值，并处理 `map[string]string` / `[]string` 工具结果。实际工具
  执行参数仍保留给策略与审批使用。
- **执行清理。** 启动失败时清理已进入的 middleware；`AfterRun` 出错后继续执行
  剩余回调；失败运行即使没有 Result 也会释放调用限制和工具选择状态。原始执行
  错误保持为主错误。
- **取消与并行。** 取消后不再启动新工具，包括等待并行槽位的工具。
- **上下文裁剪。** 用标记替换旧消息但消息数量不变时，仍采用裁剪结果。
- **OpenAI-compatible 适配器。** 缺少 `[DONE]` 或 finish reason 的截断流会被拒绝；
  cached prompt tokens 会映射；多模态块和 schema 响应格式不再被静默丢弃。
- **调度、formatter 与进程 containment。** 拒绝非法调度；报告逐文件格式化失败；
  串行化 Windows Job Object 句柄操作。
- **一致性门禁。** Go、C 及各语言 runner 在已列出的范围内拒绝缺失或空向量组。

## 升级

```bash
go get github.com/axisvela/praxo-core/v2@v2.5.1
```

从 2.5.0 升级无需修改源码。本版本不改变插件 manifest、事件名、stream kind 或
其他 wire 契约。

语言 Core 实现和适配器独立版本化；它们的 PII/runner 修复需要单独语言或适配器
tag，本 core tag 不会发布它们。

## 验证

- release commit 必须通过根模块测试、vet、build、race、fuzz、staticcheck 和
  govulncheck。
- `api/2.5.1.txt` 相对 `api/2.5.0.txt` 没有新增导出声明。
- 需要严格 docs 构建和同 SHA CI/docs 成功后才运行发布 job。
- 发布 source archive、SBOM、checksums 和 release manifest。

## 限制

- PII 脱敏不覆盖实际工具执行参数、错误字符串、事件载荷或任意结构体；这些信任
  边界由产品负责。
- Linux 进程 containment 仍弱于 Windows Job Object；cgroup v2 和确定性 WASM fuel
  仍开放。
- Workspace/session 适配器仍只做离线一致性测试；不声明 live provider 或生产就绪。
- 这些检查不构成独立安全审查或生产部署证明。
