# PRAXO-CORE 2.3.1

**发布日期：** 2026-10-23
**标签：** annotated `v2.3.1`（未配置签名密钥）

PRAXO-CORE 2.3.1 是加固 2.3.0 生命周期与文档表面的补丁版本。它不新增任何
导出 `pkg/...` 声明。

## 重点

- **A2A gRPC 覆盖：** 适配器在 JSON-RPC 测试之外新增进程内 gRPC
  client/server 往返测试。
- **Wait/Prune 正确性：** `SubagentManager.Wait` 会向所有并发等待者返回终态
  快照，即使任务在等待期间被清理。
- **事件驱动示例：** `examples/multiagent` 与多 Agent 文档改用
  `SubagentManager.Wait`，不再轮询。
- **更安全的 recipe：** sandbox 策略 recipe 同时接受 `[]string` 和 `[]any`
  命令参数，失败时拒绝，并且不再引用作用域外的变量。
- **流式用量文档：** OpenAI 兼容 recipe 补充 `IncludeUsage`。
- **已发布消费验证：** `tests/consumer` 实际运行已发布核心的 `Wait`/`Prune`
  生命周期。
- **文档门禁：** 文档工作流在 pull request 上执行
  `mkdocs build --strict`。

## 升级

```bash
go get github.com/axisvela/praxo-core/v2@v2.3.1
```

2.3.0 的消费者无需修改源码。`api/2.3.1.txt` 与 `api/2.3.0.txt` 相同。

## 可选模块

不变：`adapters/multiagent/v0.2.0`、`adapters/mcp/v0.3.0`、
`adapters/otel/v0.2.0`、`adapters/anthropic/v0.1.0`、
`adapters/gemini/v0.1.0`、`adapters/harmovela/v0.1.0` 和
`adapters/a2a/v0.1.0`。

## 验证

- 核心、适配器、示例与已发布消费测试的 test/vet/build 通过。
- 文档通过 `mkdocs build --strict`。
- staticcheck 与 govulncheck 通过。
- Linux CI 仍是 race detector 门禁。

## 限制

- 适配器测试是确定性协议测试，不代表实网服务或生产验证。
- A2A 覆盖进程内 JSON-RPC 与 gRPC 往返，不代表外部 peer 互操作。
- 多 Agent 仍是子 Agent 委派加可选 supervisor 模块，不是持久化图运行时。
