# PRAXO-CORE 2.3.5

**发布日期：** 2026-10-24

本补丁收紧 scheduler 的 disable 语义。不新增、删除或修改导出 `pkg/...` 声明。

## Scheduler

禁用 schedule 现在会：

- 在持有引擎锁时重新检查 `Enabled`，拒绝尚未开始的回调；
- 在 `SetEnabled(false)` 返回前等待已经在运行的 dispatch 完成。

此前，已通过 Enabled 检查的回调可能在 disable 返回后继续 dispatch。新行为使
该保证在 race detector 下可确定复现。

这是进程内 scheduler 保证，不是持久化调度器、lease/fencing 系统或 exactly-once
执行承诺。
