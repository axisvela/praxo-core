# PRAXO-CORE 2.4.0

**发布日期：** 2026-10-24

PRAXO-CORE 2.4.0 是一次采用面更新。它不改变任何导出 `pkg/...` 声明，也不声称
已完成生产或外部验证。

## 重点

- **流式快速开始。** `examples/quickstart` 通过 `agent.Options.OnDelta` 输出
  文本增量，生命周期事件写入 stderr，并带有确定性的 SSE 回归测试。
- **MCP 资源和提示词示例。** `examples/ecosystem/mcp` 是独立模块，使用内存
  MCP 服务器列出并读取资源和提示词，避免 MCP SDK 进入核心模块。
- **记忆召回基准。** `BenchmarkAgentMemoryRecall` 使用确定性的 20 条记录测量
  Agent 循环的召回开销。
- **发布文档。** 可选模块使用独立的 `adapters/<name>/vX.Y.Z` 标签，文档已补充
  说明。
- **CI 覆盖。** 新的 MCP 示例已纳入 examples 与跨平台模块安全任务。

## 升级

```bash
go get github.com/axisvela/praxo-core/v2@v2.4.0
```

从 2.3.6 升级无需修改源码。`api/2.4.0.txt` 与 `api/2.3.6.txt` 相同。可选适配器
版本不变。

使用经过测试的 Go 1.26.10。

## 验证

- 本地全量测试、vet 和 build 通过。
- quickstart SSE 测试和 MCP 示例测试通过。
- 基准场景（含记忆召回）使用 `-benchtime=10x` 运行通过。
- `mkdocs build --strict` 通过。
- 这些检查不构成实网提供商、部署、外部采用或独立安全验证。
