# PRAXO-CORE 2.1.0

**发布日期：** 2026-10-22

PRAXO-CORE 2.1.0 是聚焦采用体验的增量版本。`pkg/...` API 与 2.0.0 保持一致。

## 重点

- **OpenAI 兼容适配器。** `adapters/openaicompat` 支持工具调用、工具选择、
  usage 统计和 SSE 流式输出。
- **MCP 工具网关。** `adapters/mcp` 将 MCP 工具映射到 `tool.Gateway`，并作为
  独立模块发布。
- **可运行示例。** Quickstart、reference workspace Agent、生态适配器骨架，
  以及真实的 NOETIVELA/Mnemovela/GNOSIVELA SDK recipes。
- **文档与 Recipes。** 中英文文档站、采用指南、集成 recipes、基准测试，以及
  更完整的 AxisVela 对比。
- **社区。** Contributing、Code of Conduct、issue/PR 模板和 GitHub Discussions。

## 升级

```bash
go get github.com/axisvela/praxo-core/v2@v2.1.0
```

2.0.0 的使用方无需修改源码。导出的 `pkg/...` API 和 `api/2.1.0.txt` 与
`2.0.0` 一致。

## 新模块与包

| 包 | 模块 | 用途 |
| --- | --- | --- |
| `adapters/openaicompat` | `github.com/axisvela/praxo-core/v2` | 带流式输出的 OpenAI 兼容模型适配器 |
| `adapters/mcp` | `github.com/axisvela/praxo-core/adapters/mcp` | 通过 `tool.Gateway` 暴露 MCP 工具 |

MCP 模块标签为 `adapters/mcp/v0.1.0`。

- GitHub Release 附带 SBOM 和校验和
- 文档站通过 `mkdocs build --strict` 部署

## 说明

- NOETIVELA SDK 只暴露文本内容，不暴露工具调用。需要工具调用时应使用自定义
  HTTP 适配器。
- GNOSIVELA 尚无 `v3` semver 标签；SDK recipe 固定 pseudo-version。
- MCP 认证绑定在客户端会话上；网关的 token 参数会被忽略。
