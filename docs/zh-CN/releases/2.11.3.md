# PRAXO-CORE 2.11.3

**发布日期：** 2026-11-27

PRAXO-CORE 2.11.3 是 Go 参考核心的文档版本。它在根 README 中加入场景教程与参考应用列表，
并让公开注册表、支持与证据页面与当前已发布版本（包括 Java 0.12.2）保持一致。本版本不改变
导出的 `pkg/...` API，也不改变共享 wire 契约。

## 重点

- 根 README 列出代表性场景教程与参考应用组合，并链接到源码和验收限制。
- 注册表与支持页面标识 Go `v2.11.3` 和 Java `0.12.2`。
- 本版本不包含 Go 源码或 wire 契约变更。

## 升级

运行 `go get github.com/axisvela/praxo-core/v2@v2.11.3`。无需修改代码。
