# PRAXO-CORE 2.11.2

**发布日期：** 2026-11-27

PRAXO-CORE 2.11.2 是文档修正版本。它刷新公开注册表证据链接与发布文档，使它们指向
当前已发布版本。本版本不改变导出的 `pkg/...` API，也不改变共享 wire 契约。

## 重点

- 公开证据链接与各语言包当前注册表版本一致。
- 发布说明、索引与支持页面将 `2.11.2` 标识为当前框架版本。
- 本版本不包含 Go 源码或 wire 契约变更。

## 升级

运行 `go get github.com/axisvela/praxo-core/v2@v2.11.2`。无需修改代码。
