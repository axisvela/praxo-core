# PRAXO-CORE 2.11.0

**发布日期：** 2026-11-26

PRAXO-CORE 2.11.0 是 Go 参考核心的文档与打包版本。它将可运行示例迁移到
`language/go/examples`，在各语言发布页加入场景教程和 AI-native 参考应用链接，
并刷新独立语言源标签的发布元数据。本版本不改变导出的 `pkg/...` API，也不改变共享
wire 契约。

## 重点

- Go 可运行示例统一位于 `language/go/examples`，仓库根目录聚焦框架与共享规范。
- 各语言发布页在源码与包元数据之外，链接场景教程和 AI-native 参考应用。
- README、registry 入口和文档站提供统一的社区发现链接。
- 每个声明的语言 SDK 发布独立的 minor 源版本；包 registry 仍独立版本化。

## 升级

Go 代码无需修改。若引用了旧根目录 `examples/`，请更新为
`language/go/examples/`。
