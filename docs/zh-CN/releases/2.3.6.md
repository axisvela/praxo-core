# PRAXO-CORE 2.3.6

**发布日期：** 2026-10-24

本次补丁修复 `pkg/formatter` 的运行时和可变状态问题，不改变任何导出
`pkg/...` 声明。

## Formatter

- `Formatter.Run` 对空命令返回错误，不再 panic。
- `List`、`AllAvailable` 和 `Detect` 不再向调用方暴露注册表的扩展名切片。
- `WatchFormat.FormatAll` 返回文件系统遍历错误，不再始终返回 nil。
- 测试覆盖未知扩展名、大小写不敏感检测、调用方修改隔离、空命令和失败命令、
  缺失目录以及真实 `gofmt` 格式化。

格式化器检测仍选择第一个可用注册项。命令按空白拆分，不支持带引号参数；
格式化不是沙箱。

## 验证

- 本地全量测试、vet 和 build 通过。
- `pkg/formatter` 语句覆盖率从 4.7% 提升到 83.3%。
- 导出 API 与 2.3.5 相同。
- 这些检查不构成生产或外部验证。

## 升级

```bash
go get github.com/axisvela/praxo-core/v2@v2.3.6
```

使用经过测试的 Go 1.26.10。从 2.3.5 升级无需修改源码。可选适配器版本不变。

本发布环境未配置签名密钥。标签为附注标签而非加密签名；校验和与 SBOM 由发布
