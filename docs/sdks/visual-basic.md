# Visual Basic Sample

Visual Basic consumes the C# / .NET SDK assembly. It is a sample, not an
independent agent loop or contract implementation.

From the repository root, use the .NET SDK to run:

```bash
dotnet run --project csharp/samples/VbSample
```

See the [C# / .NET SDK](csharp.md) for runtime requirements, supported features,
contract version, and limitations, and the
[VB sample source](https://github.com/axisvela/praxo-core/tree/main/csharp/samples/VbSample)
for usage. No separate Visual Basic package or release is implied.
