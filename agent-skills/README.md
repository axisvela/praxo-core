# Coding-Agent Skill Templates

Optional, tool-neutral skill templates for coding tools. Repository presence
does not imply installation or automatic discovery.

- [PRAXO-Integration](praxo-integration/) - integrate a published package with
  explicit tool scope, denial tests, final-argument reauthorization, and
  governed acceptance checks.

The canonical instructions are in
[For Coding Agents](../docs/getting-started/coding-agents.md). Runtime skills
loaded by an executing agent are a separate concept with separate provenance and
trust requirements.
