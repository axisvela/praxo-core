# MCP

This example uses a caller-owned in-process transport with the Elixir MCP
client. It covers initialize, `tools/list`, and `tools/call` without a server
process.

```bash
elixir -pa language/elixir/build/ebin language/elixir/examples/mcp/mcp.exs
```

Expected output:

```text
Elixir MCP example passed
```
