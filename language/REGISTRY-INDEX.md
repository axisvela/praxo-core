# Language Registry and Coding-Agent Entries

Every language directory contains a registry-facing introduction and two
machine-readable entries. Registry pages render the package README/manifest;
these files keep the language-specific install, version, registry, and
coding-agent boundaries in one place.

Each registry is independent. Verify the published version before relying on a
feature, and do not treat a source tag or these files as registry publication
evidence.
