# TypeScript Education Tutoring (PE-01)

Tracks a fixed learner fixture and drafts a graded Socratic question for review.
No adaptive model or issued grade.

## Why this language and runtime?

- **Selection basis:** TypeScript is common in education products; the question
  review can stay in the existing app.
- **Demonstrated fit:** Three fixed attempts with one misconception yield a
  draft-only question focused on unit conversion.
- **Choose when:** Evaluating a bounded tutor seam beside human instruction.
- **Do not choose when:** Seeking an adaptive tutor or automatic grading. Compare
  the pedagogy and learner-data policy first.
- **Evidence limit:** One fixed learner only; no personal data, adaptive model,
  grade or learning-outcome claim.

## Run

```bash
npm ci
npm test
```

Expected output:

```text
TypeScript PE-01 education-tutoring tutorial: all checks passed
```

No learner account, grading or adaptive model is implemented. Consent and
instructional review belong to the consumer.
