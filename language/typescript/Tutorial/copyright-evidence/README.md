# TypeScript Copyright Evidence (LJ-05)

Compares fixed authorized assets and drafts a review-only evidence packet. No
broad crawl, DMCA notice or infringement verdict.

## Why this language and runtime?

- **Selection basis:** TypeScript fits rights-management tooling; the evidence
  review can stay in the existing workflow.
- **Demonstrated fit:** Three fixed assets yield two matches and a draft-only
  packet with no verdict.
- **Choose when:** Assembling a bounded evidence packet for human rights review.
- **Do not choose when:** Seeking automatic notices or infringement
  adjudication. Compare legal review and platform policy first.
- **Evidence limit:** Fixed assets only; no crawl, hash database, notice or legal
  conclusion.

## Run

```bash
npm ci
npm test
```

Expected output:

```text
TypeScript LJ-05 copyright-evidence tutorial: all checks passed
```

No DMCA notice, crawl or infringement verdict is implemented. Legal review and
asset authorization belong to the consumer.
