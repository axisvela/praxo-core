# Octave Advanced Delegation

Octave wrappers for the shared MATLAB/Octave delegation and governance examples.

```bash
octave-cli language/octave/examples/advanced-delegation/run_delegation.m
octave-cli language/octave/examples/advanced-delegation/run_governance.m
```

See `language/matlab/examples/advanced-delegation/README.md` for expected output
and limits.
