# Ruby Supply Disruption (IN-03)

A fixed supplier network with a port closure yields an alternative supplier
(`supplier-2`) and a review-only sourcing plan. No purchase order, supplier
contact or live logistics feed is used.

## Why this language and runtime?

Ruby fits existing procurement and back-office automation; the tutorial keeps the
alternative-sourcing review beside that data and computes the selection directly.

Evidence limit: three fixed suppliers only; no live index, contract terms,
purchase order or delivery guarantee.
