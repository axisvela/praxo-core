# Dart Marketing Segments (CS-04)

Fixed customer spend produces two high-value customers and a review-only campaign
draft. No customer records, sends or live model.

## Why this language and runtime?

Dart fits existing Flutter or Dart commerce apps; the tutorial computes actual
segment counts and keeps the campaign review in that runtime.

Evidence limit: three fixed spend values only; no customer data, segmentation
model, message send or conversion claim.
