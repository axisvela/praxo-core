# Swift Core Release Notes

## 0.5.0 - 2026-11-13

- OpenTelemetry OTLP/HTTP sink over an injected `OtelTransport`.
- Retriever document/query/limit seam with `FuncRetriever`.
- Synchronous subagent delegation seam with `SubagentManager`.
