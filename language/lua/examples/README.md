# Lua Examples

- [`advanced-delegation/`](advanced-delegation/): application-level governed
  parent/child delegation.
- [`consumer/`](consumer/): published LuaRocks `praxo-core==0.7.1-1` starter
  with deterministic allow/deny checks.
- [`hitl/`](hitl/): approval and edit-reauthorization for a write tool.
- [`representative-chain/`](representative-chain/): deterministic MCP, governed
  child delegation, OTel/Harmovela events, and edited denial.
- [`session-checkpoint/`](session-checkpoint/): multi-turn history save, reload,
  and continue.

The consumer installs a published rock. The HITL and checkpoint examples run
from the repository source.
