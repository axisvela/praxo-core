# Publishing the Delphi/Free Pascal Core

Source tag `delphi/v0.2.1`. The package is not in the Lazarus Online Package
Manager (OPM).

Add an OPM-compatible package description and source manifest, then submit the
package entry through the OPM package list on GitHub. Run the Free Pascal tests
and API snapshot first.

Verify installation from OPM in a clean Lazarus/Free Pascal environment.
Commercial Delphi and other targets remain unverified. No separate account is
required beyond GitHub.
