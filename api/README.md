# API Snapshots

Each `<version>.txt` is the normalized exported API for `pkg/...`, generated by:

```powershell
.\scripts\api-snapshot.ps1 -Version <version>
```

Commit a snapshot for every release. Before tagging, diff the previous release
against the candidate:

```powershell
.\scripts\api-diff.ps1 -From <previous> -To <candidate>
```

The snapshot is a release gate, not a generated build artifact. Review every
difference and record intentional changes in `CHANGELOG.md` and
`docs/05-compatibility.md`.
