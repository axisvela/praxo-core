Capability packages:


The root package keeps Agent, Options, New, Run, and compatibility aliases.
New capabilities should live in the matching subpackage and be re-exported from
aliases.go when they are part of the public agent API.

### github.com/axisvela/praxo-core/v2/pkg/plugin/host/process
it runs a runtime plugin as a child process and mediates typed invocations over
a local authenticated JSON-Lines channel on the child's stdio. The channel
is authenticated by a per-process random token provisioned to the child via
environment, never argv.

The host enforces process containment and resource limits through the
platform supervisor (a Windows Job Object or POSIX per-process rlimits),
bounds invocations by the caller context and the configured InvokeTimeout,
and guarantees cancellation: a canceled or timed-out invocation terminates the
child process, reaps it, fails sibling calls, and emits terminal evidence.
The package is stdlib-only apart from the platform supervisor.

Containment guarantees are platform-specific and intentional:

  - Windows (RequireLimits): the child is created suspended and assigned to a
  - Linux: containment uses per-process rlimits plus a dedicated process group
  - Other platforms: no supervisor; a RequireLimits host fails to start.
