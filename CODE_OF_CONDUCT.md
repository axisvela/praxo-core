# Code of Conduct

## Our Pledge

We want PRAXO-CORE to be a welcoming project for everyone. We pledge to make
participation respectful and harassment-free, regardless of experience,
identity, background, or affiliation.

## Expected Behavior

- Be respectful and assume good faith.
- Focus criticism on code and ideas, not people.
- Give actionable feedback and accept feedback gracefully.
- Respect privacy and do not publish private information.
- Follow the project's security and licensing rules.

## Unacceptable Behavior

- Harassment, discrimination, threats, or personal attacks.
- Sexualized language or imagery.
- Trolling, deliberate disruption, or sustained bad-faith argument.
- Publishing private information without permission.
- Other conduct that maintainers reasonably consider inappropriate.

## Scope

This code applies to issues, pull requests, discussions, reviews, and other
project spaces.

## Enforcement

Maintainers may remove content, close threads, or restrict participation when
behavior violates this code. Reports can be sent privately through the
repository's GitHub Security Advisories or to the maintainers listed on the
repository profile. Reports will be handled as confidentially as practical.

## Attribution

This is a short project-specific code of conduct, not a legal document.
